Magnetic Button

Interaksi selektif untuk tombol konversi utama (CTA). Tombol bergeser halus beberapa pixel mengikuti arah kursor dan kembali elastis saat kursor keluar.

Magnetic Proximity Area — Hover near button
Proximity: Move cursor inside zone
Proximity Max ±8px delta (Restrained)
Spring Reset 300ms cubic-bezier(0.2, 0.8, 0.2, 1)
A11y Constraint Disabled on touch & reduced motion 
// Vanilla JS Proximity calculation
const bounds = btn.getBoundingClientRect();
const dx = (e.clientX - (bounds.left + bounds.width / 2)) * 0.25;
const dy = (e.clientY - (bounds.top + bounds.height / 2)) * 0.25;
btn.style.transform = `translate(${dx}px, ${dy}px)`;

// On mouse leave:
btn.style.transform = 'translate(0, 0)';
