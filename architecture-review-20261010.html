Problem: Daftar link ada di 2 tempat per halaman dan di 5 halaman, jadi Contact kehilangan link Library di nav dan drawer.

Solution: Satu module memegang daftar link dan state halaman aktif; tiap halaman hanya menyatakan "saya halaman About".

  • Drift antar halaman hilang
  • Head SEO (canonical, OG) ikut terpusat
  • Link bersih /about tanpa redirect .html

Pisahkan perilaku chrome (tema + drawer) dari portfolio grid

Strong in-process
  • portfolio.js (15.6 KB, dimuat di About, Contact, Portfolio)
  • library.js (13.4 KB, salinan tema + drawer sendiri)

After

site-chrome.js
tema + drawer + satu key + apply sebelum paint
portfolio-grid.js (hanya Portfolio)
library.js (hanya Library)

About dan Contact memuat site-chrome saja.

Problem: portfolio.js berubah karena dua alasan tak berkaitan (isi portfolio dan perilaku chrome), dan perilaku chrome ditulis dua kali dengan key berbeda.

Solution: Satu module untuk tema dan drawer di setiap halaman; data dan render grid pindah ke module yang hanya dimuat di Portfolio.

  • locality: bug tema diperbaiki sekali
  • Tema terapply sebelum paint (tanpa flash)
  • About berhenti memuat kode grid
  • Drawer: satu tempat untuk perbaikan aria-hidden dan Escape

Problem: JS menulis style langsung dan memakai 3 variabel yang tidak ada di stylesheet, sehingga seam token terlewati dan header CSS ("monochrome, locked") tidak ditaati.

Solution: Preview card memakai class dari stylesheet; variabel yang dipakai wajib terdefinisi, atau dihapus.

  • Dark theme otomatis konsisten
  • JS menyusut jadi data + markup
Verifikasi: variabel tak terdefinisi diperiksa lewat pencarian di portfolio.css dan portfolio.js. Dampak visual di halaman Portfolio belum saya lihat langsung.
